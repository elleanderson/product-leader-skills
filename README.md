# Product leader skills

Six working methods from a product leader who has shipped machine learning products since 2017, packaged as skills for AI coding and knowledge agents (Claude Code, Cursor, Codex, GitHub Copilot, Windsurf, Gemini CLI and anything else that reads the open `SKILL.md` format).

Each skill is a readable instruction file. Nothing runs on your machine beyond the installer. Install one, or all six:

```bash
npx skills add https://github.com/elleanderson/product-leader-skills
npx skills add https://github.com/elleanderson/product-leader-skills --skill ai-feature-readiness
```

| Skill | What it makes your agent do |
|---|---|
| `ai-feature-readiness` | Put any AI feature through the nine questions before the demo: outcome without the technology, wrong-answer cost, the moment after, kill criteria. |
| `ai-outcome-measures` | Build the measurement plan for an AI feature: accuracy as experienced, wrong-answer cost, the moment after, retained use, unit economics at ten times the volume. |
| `opportunity-brief` | Draft and stress-test the nine-box opportunity brief, and refuse to fill a box it cannot fill honestly. |
| `discovery-synthesis` | Turn interview notes into behaviour rather than testimony, and into the decision that should change within the month. |
| `product-sense-drill` | Run a product sense interview the way Meta grades it, with the answer spine and the interviewer rubric. |
| `product-ops-check` | Run the twelve-point Product Ops health check against what an organisation actually does and say what to fix first. |

## Who wrote these

Elle Anderson is a technical product leader: computer vision at LEGO scale, Bloomberg's most-used custom GPT, product organisations rebuilt at banks, health and retail businesses. The methods are the ones she uses in her own product functions and teaches in [The Anderson MTHD](https://andersonco.uk/work-with-me.html). The long-form versions, the field notes and the printable tools live at [andersonco.uk](https://andersonco.uk/ai.html).

## Voice

The skills are deliberately opinionated. They will push back, ask the uncomfortable question and refuse to invent evidence. If you want an agent that agrees with you, these are the wrong skills.
